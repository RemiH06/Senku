### General Description
A bot that uses de OpenAI API to answer to any question.

## Installation

1. Install requirements with the following command :

   `pip install -r requirements.txt`

2. Make sure you have this in a file named ".secrets"

    `OPENAI_API_KEY=XXXXXXXXXXXXXXXXXXXXXXXX`
    `DISCORD_TOKEN=XXXXXXXXXXXXXXXXXXXXXXXXXX`

## Launch arguments

- !senku [question]
- !hi to say hi
- !info to check info
- !help to ask for help
- !commands to see available commands
